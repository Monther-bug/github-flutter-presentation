# GitHub Teams & Flutter API Networking — Presentation

A single-file, web-based slide deck teaching:

1. The professional **GitHub team workflow** (issues, branches, PRs, merging).
2. **Flutter HTTP networking** — making GET requests, parsing JSON, and rendering with `FutureBuilder`.

Built with vanilla HTML, CSS, and JavaScript — no build step, no dependencies.

## How to view

Open `index.html` in any modern browser.

```
open index.html
```

## What's inside (10 slides)

| #  | Slide                                                    | Topic                |
|----|----------------------------------------------------------|----------------------|
| 1  | The Professional Developer (title)                       | Intro                |
| 2  | The GitHub Team Workflow                                 | Workflow overview    |
| 3  | Issues, Branch Names & Pushing                           | Issues + branches    |
| 4  | Pull Requests & Merging                                  | PR review            |
| 5  | The Pivot: Connecting to APIs                            | App ↔ Server         |
| 6  | A GET Request is Like Ordering Coffee ☕                 | Beginner analogy     |
| 7  | What Comes Back? The Response                            | Status codes + body  |
| 8  | Fetching Data: The GET Request                           | Dart code            |
| 9  | Creating a Product Model                                 | `fromJson` factory   |
| 10 | Putting It Together: FutureBuilder                       | UI + loading state   |

Slides 6 and 7 are designed to make the jump into HTTP networking gentle —
they introduce the concept and the response structure visually before any
Dart code appears.

## Design

- Dark slate/navy theme with GitHub-style purple and teal accents.
- Smooth slide-up fade transitions between slides.
- Gradient progress bar across the top.
- CSS-only visual diagrams (flow charts, PR mockup, API arrows, status pills).
- Dart code blocks with GitHub Dark syntax highlighting.

## Controls

- **→** / **Space** / **PageDown** — next slide
- **←** / **PageUp** — previous slide
- **Home** / **End** — jump to first / last slide
- Or click the navigation buttons at the bottom of the screen.

The GitHub Team Workflow

Issues, Branch Names & Pushing

An Issue is a ticket describing a bug or a new feature — a written record of work to do. When you start working on an issue, name your branch based on its purpose using clear prefixes so your teammates instantly know what the branch is for.

feature feature/login-screen
bugfix bugfix/crash-on-start

When your code is ready, push it to GitHub so your team can see it:

git push origin your-branch-name

Fetching Data: The GET Request

A GET request asks a server for data. Since downloading takes time (the network is slow!), we wrap it in a Future and use async / await so the app doesn’t freeze while it waits.

Dart 
import 'package:http/http.dart' as http;

Future<void> fetchProduct() async {
  final response = await http.get(
    Uri.parse('https://api.example.com/products/1'),
  );

  if (response.statusCode == 200) {
    // Success! The server sent us the product.
    print(response.body);
  } else {
    throw Exception('Failed to load product');
  }
}

Creating a Product Model

Flutter doesn’t understand raw JSON strings natively. We build a Product class with three fields — title, description, and image — and convert JSON into a real Dart object using a fromJson factory.

📥 Raw JSON
{
  "title": "Coffee Mug",
  "description": "A nice mug.",
  "image": "mug.png"
}
→ fromJson()
📦 Product Object
Product(
  title: 'Coffee Mug',
  description: 'A nice mug.',
  image: 'mug.png',
)
Dart 
class Product {
  final String title;
  final String description;
  final String image;

  Product({required this.title, required this.description, required this.image});

  factory Product.fromJson(Map<String, dynamic> json) {
    return Product(
      title: json['title'],
      description: json['description'],
      image: json['image'],
    );
  }
}

Putting It Together: FutureBuilder

FutureBuilder is a magic Flutter widget that watches your Future for you. You only need to tell it what to show while loading, and what to show when the data arrives. That’s it!

While loading…
show a spinner
→
✓
Got the product!
show image + title + description
Dart 
FutureBuilder(
  future: fetchProduct(),
  builder: (context, snapshot) {
    if (snapshot.hasData) {
      final product = snapshot.data;            // our Product object
      return Column(children: [
        Image.network(product.image),         // the image
        Text(product.title),                  // the title
        Text(product.description),            // the description
      ]);
    }
    return CircularProgressIndicator();        // Still loading…
  },
)
